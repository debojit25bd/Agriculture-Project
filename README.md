🌿 Smart Agriculture Soil Moisture Monitor
An Arduino-based IoT project to monitor soil moisture levels in real-time, display data on an I2C LCD screen, alert users via a buzzer, and transmit data wirelessly via Bluetooth (ZS-040 / HC-05).

🛠️ Components Required:
Arduino Uno / Nano
Soil Moisture Sensor (with Comparator Module)
16x2 I2C LCD Display
ZS-040 / HC-05 Bluetooth Module
Buzzer
Jumper Wires & Breadboard
🔌 Pin Connections:
Soil Moisture Sensor (AO) \rightarrow Arduino A0
Buzzer (+) \rightarrow Arduino D6
I2C LCD (SDA) \rightarrow Arduino A4 (Nano)
I2C LCD (SCL) \rightarrow Arduino A5 (Nano)
Bluetooth (TX) \rightarrow Arduino Rx
Bluetooth (RX) \rightarrow Arduino Tx
